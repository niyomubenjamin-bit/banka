# Admin Features

Based on the project specification, the Admin role has the following capabilities:

## User Management
- Create staff users with the role "staff".
- Create other admin users with the role "admin".
- View all user accounts.
- View a specific user account.
- Activate or deactivate users.
- Delete users.

## Account Management
- Activate or deactivate a bank account.
- Delete a specific user account.

## Dashboard & Reporting
- Access a dashboard that displays statistics for:
  - All accounts
  - Dormant accounts
  - Active accounts
- View reports on money deposited and withdrawn.
- Filter financial reports by a specific date range.
